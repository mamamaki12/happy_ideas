メニューまるわかり

メニューを撮ると、選んだ言語で料理の説明とアレルゲンの目安を表示。店員さんに見せる画面つき。

このアプリについて（#106）

ニーズ: 訪日客4,268万人・海外旅行・食物アレルギー

実現性 B（Webで動くが制約あり）: 多言語の説明は1回のAPI呼び出しで済む。アレルゲンは「推定」であることを必ず表示。店員さんに見せる全画面表示はWebだけで作れる。

入力した文章や写真は、AIサーバーが設定されているときだけ、答えを作るために Anthropic の Claude API へ送られます（このサイトでは保存しません）。履歴などはこの端末の中だけに保存されます。
