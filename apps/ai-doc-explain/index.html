このアプリについて（#105）

ニーズ: 高齢化・単身高齢94万世帯・苦労キャンセル

実現性 B（Webで動くが制約あり）: 画像入力＋読み上げで、高齢の利用者にも届く形にできた。法律・医療の最終判断はさせず、発行元への確認を必ず表示する。マイナンバー等が写る点はUIで注意。

入力した文章や写真は、AIサーバーが設定されているときだけ、答えを作るために Anthropic の Claude API へ送られます（このサイトでは保存しません）。履歴などはこの端末の中だけに保存されます。
