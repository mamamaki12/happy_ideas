英会話ロールプレイ

カフェ・道案内・面接などの場面で、声か文字で英会話を練習。AIが相手役とやさしい添削をする。

このアプリについて（#108）

ニーズ: 語学のAI会話練習が標準化（既存アプリの会話は浅いとの不満）

実現性 B（Webで動くが制約あり）: 会話の履歴（最大12ターン）を毎回送る。音声認識（英語）と読み上げは Chrome と Safari で動く。1回の会話のAPI費用が積み上がるので回数制限が重要。

入力した文章や写真は、AIサーバーが設定されているときだけ、答えを作るために Anthropic の Claude API へ送られます（このサイトでは保存しません）。履歴などはこの端末の中だけに保存されます。
