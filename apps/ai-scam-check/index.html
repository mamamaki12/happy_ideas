あやしいメッセージ判定

届いたSMS・メールを貼るかスクショを選ぶと、詐欺の可能性・手口・理由・次にすることを教えてくれる。

このアプリについて（#102）

ニーズ: 直近1か月で45.2%が詐欺メッセージを受信、特殊詐欺被害は半年で1,816億円

実現性 B（Webで動くが制約あり）: 判定対象の文面そのものが攻撃者の文章なので、プロンプトインジェクション対策（タグで囲む・指示に従わない・出力の型を固定）が必須。「安全」と断定させない設計にした。

入力した文章や写真は、AIサーバーが設定されているときだけ、答えを作るために Anthropic の Claude API へ送られます（このサイトでは保存しません）。履歴などはこの端末の中だけに保存されます。
