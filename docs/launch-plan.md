# 公開と検証のプラン（製品版2つ）

[競合調査](./competition.md)で残った2つ — **ラリーメーカー** と **推し活手帳** — を、実際に使ってもらって「本当に需要があるか」を確かめるための計画です。

## 共通: 公開の準備（チェックリスト）

- [ ] GitHub Pages で公開（[README](../README.md) の手順。Settings → Pages → Source を「GitHub Actions」）
- [ ] 実機で確認（[feasibility.md の「実機で確かめること」](./feasibility.md)）: iPhone Safari・Android Chrome でカメラ、位置情報、ホーム画面に追加
- [ ] [プライバシーポリシー](../products/privacy.html) に運営者名と連絡先を記入
- [ ] 独自ドメインを使うなら `_headers` 相当のヘッダー（CSPの frame-ancestors など）をホスティング側で設定（GitHub Pages では不可 → Cloudflare Pages / Netlify を推奨）
- [ ] 問い合わせ窓口（Googleフォームなど）を用意

## ラリーメーカー

### 誰に売るか
| 対象 | 困りごと | 今の手段 |
|---|---|---|
| 小学校・PTA・子ども会 | 校外学習や地域のお祭りで、スタンプ台紙を作るのが手間 | 紙の台紙（印刷・配布・回収） |
| 町内会・小さな商店街 | 有料サービス（月4万円）は高すぎる | 紙、またはやらない |
| 企業の社内イベント・研修 | 歓迎会やオリエンテーリング | 紙、Googleフォーム |
| 結婚式の二次会・同窓会 | 会場内・周辺のゲーム | なし |

### 検証のステップ
1. **知り合いの小さなイベントで1回使ってもらう**（2〜3週間）
   - 主催者の作成時間（目標: 15分以内）、参加者の完走率（目標: 60%以上）、スタンプが押せなかった問い合わせの数を記録
2. **PTA・町内会向けに無料公開**し、SNS（X・Instagram の「PTA」「子ども会」界隈）とnoteで紹介
3. **お金を払う理由があるか確認**: 「参加人数の集計」「景品応募の受付」「ロゴ入りポスター」を有料オプション（例: 1イベント 980〜2,980円）として提示し、申し込み意向を聞く

### 測る指標
| 指標 | 意味 | 目標の目安 |
|---|---|---|
| ラリー作成数 / 月 | 主催者に刺さっているか | 公開3か月で 30件 |
| 1ラリーあたりの参加者数 | イベントの規模 | 20人以上 |
| 完走率 | 体験の良さ（押せない・迷う問題） | 60%以上 |
| 有料オプションの申し込み意向 | 事業になるか | 作成者の10%以上 |

### 足りないもの（優先順）
1. **参加人数・完走数の集計**（主催者が一番知りたい）→ 小さなサーバー（Cloudflare Workers + D1 など、月数百円）で、匿名の完走カウントだけ送る
2. 景品応募の受付（同上）
3. 地図表示（OpenStreetMap のタイルを使うならCSPの許可が必要）

## 推し活手帳

### 誰に使ってもらうか
- 推しの数が1〜3人で、**月1万円以下**で推し活をしている人（全体の約7割 → [調査](./competition.md)）
- 「推し活アプリを入れるほどではないけど、使いすぎは気になる」ライト層 → **インストール不要**が効く

### 検証のステップ
1. **年間まとめ画像を入口にする**: 12月に「#推し活まとめ2026」として、記録がなくても「今年の推し活」を手入力で作れる簡易版を出し、SNSでの拡散を見る
2. 当落管理の需要確認: チケット先行の時期（ツアー発表直後）に、該当ファンダムのコミュニティで紹介
3. 継続率を見る（後述）

### 測る指標
| 指標 | 意味 | 目標の目安 |
|---|---|---|
| まとめ画像のシェア数 | 口コミで広がる力 | 公開1か月で 500件 |
| 7日後・30日後に使っている割合 | 本当に役立っているか | 30% / 15% |
| 当落の登録数 | 競合の主要機能に負けていないか | 利用者1人あたり月2件 |

**注意**: 端末内保存なので、指標を取るには計測の仕組みが必要。プライバシーを売りにしているので、入れるなら「匿名・件数だけ・オプトイン」に限定し、プライバシーポリシーを更新する。

### 足りないもの（優先順）
1. **Push通知**（入金期限・当落発表の通知が当落管理の価値の大半）→ Web Push 用の小さなサーバー
2. 家族・友人との共有（家族で推し活する人は支出が2.8倍 → 熱量が高い層）
3. 写真のアルバム（現状はカメラで撮って保存するだけ）

## どちらを先にやるか

**ラリーメーカーを先におすすめします。** 理由:
- 競合が「月4万円」で、価格の差がはっきりしている
- 1回のイベントで数十人に使ってもらえるので、検証が速い
- 主催者さえ見つかれば、参加者は「QRを読むだけ」なので広げやすい

推し活手帳は市場は大きいものの、競合が多く、勝つには通知（サーバー）と継続的な改善が必要です。ラリーメーカーで「小さく公開して検証する流れ」を一度回してから取り組むのが安全です。
