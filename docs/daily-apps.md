# 暮らしのアプリ6つ

トップページの「暮らしをちょっと楽にする、新作6つ」から開きます。

## どこだっけ

物の名前・部屋・収納場所・別名・写真を登録。検索はメモも含めた複数キーワードのAND検索で、全角英数字やひらがな・カタカナを同一視します。写真は端末内で最大600pxのJPEGに縮小します。収納場所を変更したら「編集」で更新します。

## すきまスイッチ

活動の所要時間・場所・必要な気力を登録し、現在の条件を選びます。「どこでも」の活動は家・外出先の両方に表示。条件に合うものだけからランダムにひとつ選べます。「できた！」は繰り返し記録可能。「1回戻す」で最後の完了を取り消します。表示する活動時間は所要時間の合計で、実測のタイマーではありません。

## ひと晩カート

欲しい物の価格・理由・商品URL・寝かせる期間を保存します。期間が過ぎると「やっぱり買う」が押せます。「今回は見送る」はいつでも可能。見送った予定金額は貯金額や実際の節約額ではありません。記録は「考え中」「買った」「見送った」で切り替えられます。

## わたしの攻略本

自分だけの発見をカテゴリ・役立つ場面・メモとして登録します。検索、カテゴリの絞り込み、お気に入り、役立った回数に対応。お気に入りを先に、次いで役立った回数順に表示します。

## そろそろ家事

最初の基準日と間隔を登録し、その後は「今日やった！」で完了を記録。次の目安は直近の完了日から計算します。完了は1日1回、取り消すと前の完了日に戻ります。間隔はユーザー自身が決める目安です。

## なくなる前に

開封日・予想使用日数・未開封のストック数を登録。「今日使い切った」で使用期間を保存し、新しい物は別の操作で開封します。ストックから開封すると1個減ります。ストックなしで「購入分を今日開封」を押すと、新たに買った物を直接使い始めた扱いになります。

最初は入力した予想日数、以降は直近5回の使用期間の平均を四捨五入して予報します。開封当日の使い切りは、0日の使用期間を学習しないため記録できません。使い切り直後は取り消せます。容量や家族の人数が変わると予報には誤差が出ます。

## 保存と制約

- 記録は各アプリ300件まで。写真付き記録はブラウザの保存容量により、それより少なくなることがあります。容量不足時は画面にエラーを表示し、保存済みデータは保持します。
- 記録はブラウザのlocalStorage内のみ。自動同期・サーバー通知はありません。ブラウザデータの削除や端末故障に備え、各アプリでJSONバックアップを保存してください。
- 復元は確認後にそのアプリだけを置き換えます。別アプリのファイル、不正な日付・URL・写真などは拒否します。
- 写真の加工・保存を含め外部APIへ通信しません。商品URLを開く場合はその外部サイトに移動します。
- 別タブの更新時は記録を再読込し、編集中の画面を閉じます。同時編集は避けてください。
- 共通UIは `products/daily-kit/`。ページを再生成する場合は `node scripts/build-daily-pages.mjs`。既存の試作110個の生成処理とは独立しています。
- 新規ロジックのテスト: `node --test tests/unit/daily-kit.test.js`。操作テスト: `npx playwright test tests/e2e/daily-kit.spec.js`。
